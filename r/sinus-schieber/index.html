Nachbauen: Ein lila Graph erscheint. Stell die Regler so ein, dass deiner genau darauf liegt.

Übersicht: f(x) = a · sin(b(x − c)) + d

Was passiertAm Graphen ablesen
aStreckung in y-Richtung. Amplitude = |a|. Ist a negativ, wird an der Mittellinie gespiegelt.|a| = (Hochwert − Tiefwert) : 2
bStreckung in x-Richtung. Periode p = 2π : b. b > 1: enger, b < 1: breiter.p = Abstand zweier Hochpunkte, dann b = 2π : p
cVerschiebung in x-Richtung. c > 0: nach rechts, c < 0: nach links.Wo die Welle die Mittellinie aufwärts kreuzt (bei a > 0)
dVerschiebung in y-Richtung. Mittellinie y = d.d = (Hochwert + Tiefwert) : 2

Wertebereich: W = [d − |a| ; d + |a|]

So zeichnest du den Graphen

  1. Mittellinie y = d zeichnen.
  2. Hoch- und Tiefwert: d + |a| und d − |a|.
  3. Start bei x = c auf der Mittellinie – aufwärts (a > 0) oder abwärts (a < 0).
  4. Eine Periode in vier gleiche Teile: Mitte → Hoch → Mitte → Tief → Mitte.

Vorsicht, Fallen

  • sin(2x − π/2): erst ausklammern: sin(2(x − π/4)). Also c = π/4, nicht π/2.
  • sin(x + π/3) = sin(x − (−π/3)): c = −π/3, also nach links.
  • Periode ist 2π : b, nicht 2π · b.
  • Amplitude ist |a|, also nie negativ.

Beispiel: f(x) = 2 · sin(½(x + π)) + 1

Amplitude 2 · Periode 2π : ½ = 4π · π nach links (c = −π) · 1 nach oben · Wertebereich [−1 ; 3]
